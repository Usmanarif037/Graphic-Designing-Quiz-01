Graphic Designing - UI/UX Quiz 01Course: Graphic Design / UI-UX   Semester: $4^{th}$   Topic: Introduction to UI/UX | Wireframes | Mockups   🎯 Project ObjectiveThe goal of this project was to design a low-fidelity wireframe for a mobile application login screen while adhering to specific usability requirements and design constraints.  📱 Wireframe RequirementsThe design includes the following mandatory UI elements:  Brand Identity: App logo placeholder and title.User Inputs: Username/Email field and Password field.Primary Action: Prominent Login button.Navigation Links: "Forgot Password" and "Sign-up" options.💡 UX AnalysisThe layout was developed with a focus on CLO-3: User-Centered Design. Key UX improvements include:  Visual Hierarchy: Using varied font weights and button shading to guide user attention to the primary action (Login).  Readability: Ensuring clear spacing and labels to minimize cognitive load.  Usability: Placing links in conventional locations to meet user expectations and improve navigation flow.  🛠️ Tools UsedWireframing Tool ( Figma,Sketch)GitHub for Version Control
